🥊 BOXING MASTERY

Soviet Style + Peekaboo Style — 12-Month Mastery Plan

STYLE PHILOSOPHY
Soviet Style (Klassik): Upright orthodox stance, long jab as a weapon, footwork-based ring control, tight defense, counter-punching. Think Lomachenko-era fundamentals. Long range dominance.
  • Jab hand extended, rear hand at chin
  • Weight on back foot (60/40)
  • Box on the outside, use the ring
  • Pivot and angle after every combo
  • Rear uppercut as primary KO weapon
Peekaboo Style (Cus D'Amato): Hands cover face, constant head movement (bobs & weaves), explosive inside fighting, both hands as equal weapons. Mike Tyson's foundation. Short range destruction.
  • Fists at cheekbones, elbows tight
  • Slip outside, ALWAYS return with a punch
  • Body-head-body combinations
  • Develop the pull counter (Tyson's specialty)
  • Combination punching with both hands

💡 TIPS FOR BOXING-RUNNERS
Zone 2 = Your Friend: Run at a pace where you can hold a full conversation. This builds the aerobic engine that fuels 12-round boxing sessions.
Don't skip Saturday long run: This is your most important run. Start slow, finish feeling like you could run more.

🗣 COMMUNICATION MASTERY
💼 INTERVIEW COMMUNICATION
STAR method: Situation → Task → Action → Result. Use for every behavioral question.
Pause before answering. 3 seconds of silence looks thoughtful, not blank. Never rush an answer.
Mirror the interviewer's energy. If they're formal, be formal. If relaxed, slightly loosen up.
Ask smart questions: "What does success look like in this role in 90 days?" shows you're already thinking like an employee.
Tell a story, not a resume. "I went from zero Java knowledge to building X project in 3 months" beats listing bullet points.
🌍 GK — TODAY'S FACTS
📰 HOW TO STAY CURRENT ON GK
Daily 15 min routine: Skim The Hindu / Indian Express headlines + one deep-read article. Quiz yourself: "What happened? Why does it matter?"
Apps: Inshorts (5-min news) · Manorama Yearbook · UPSC Wallah YouTube for organized GK
Weekly: Read one magazine feature (frontline, down to earth). It builds analytical thinking, not just trivia.
Teach-back method: After reading, close the article and explain it out loud as if teaching someone. If you can't, you didn't understand it.
